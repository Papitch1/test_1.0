# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание для HTML/Frontend-верстальщика.

## Запуск

Просто откройте `index.html` в браузере. Сборка не требуется.

Либо локальный сервер:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Стек

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox, CSS-переменные, media queries)
- Vanilla JS (ES6+, без фреймворков)

## Функциональность

- Переключение фасовки (100 / 500 / 1000 / 5000 г)
- Динамическое обновление цены, старой цены и артикула
- Кнопка «В корзину» с hover/active/focus состояниями
- Адаптив: 1440 / 768 / 375 px
